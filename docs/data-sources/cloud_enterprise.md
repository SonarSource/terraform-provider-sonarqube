# sonarqube_cloud_enterprise (Data Source)

Reads one SonarQube Cloud enterprise by its key. The provider must use a user token. Scoped organization tokens are not supported.

## Example Usage

```terraform
data "sonarqube_cloud_enterprise" "example" {
  key = "my-enterprise"
}

output "enterprise_id" {
  value = data.sonarqube_cloud_enterprise.example.id
}
```
