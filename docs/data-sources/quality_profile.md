# sonarqube_quality_profile (Data Source)

Reads a quality profile of one language by its exact name, also a built-in profile such as `Sonar way core`. Use its `key` as the `parent_key` of a `sonarqube_quality_profile`. The alpha supports SonarQube Cloud only.

## Example Usage

```terraform
data "sonarqube_quality_profile" "sonar_way_core" {
  organization = "my-organization"
  language     = "java"
  name         = "Sonar way core"
}

output "sonar_way_core_key" {
  value = data.sonarqube_quality_profile.sonar_way_core.key
}
```

### Required

- `name` (String) Exact name of the profile, with the same case.
- `organization` (String) Key of the organization that owns the profile.

### Read-Only

- `is_built_in` (Boolean) Whether the profile is a read-only built-in profile.
- `is_default` (Boolean) Whether the profile is the default profile of the language.
- `key` (String) Key of the profile.
- `parent_key` (String) Key of the profile that this profile extends. Null when it extends no other profile.
