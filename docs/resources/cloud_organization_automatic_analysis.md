# sonarqube_cloud_organization_automatic_analysis (Resource)

Sets whether new projects of a SonarQube Cloud organization get Automatic Analysis. The setting does not change the existing projects. To set one project, use `sonarqube_cloud_project_automatic_analysis`.

The organization must be on the Enterprise plan. On the other plans, SonarQube Cloud turns Automatic Analysis on for each eligible new project, and refuses a change.

`terraform destroy` removes the value of the organization. New projects then get the default of SonarQube Cloud again.

## Example Usage

```terraform
# New projects of the organization get their analyses from a CI pipeline.
# The organization must be on the Enterprise plan. The destroy of this
# resource gives new projects the default of SonarQube Cloud again.
resource "sonarqube_cloud_organization_automatic_analysis" "example" {
  organization             = "my-organization"
  enabled_for_new_projects = false
}
```
