# sonarqube_group (Resource)

Manages a SonarQube Cloud group. A change to `name` renames the group in place. A change to `organization` replaces it.

The built-in groups Members and Owners cannot be imported. A destroy of Owners can remove the administrators of the organization. Use the sonarqube_group data source to read them.

SonarQube Cloud refuses updates and deletions of a group that an identity provider synchronizes through SCIM. The change fails with the API error, and the state keeps the group. Manage such a group through the identity provider.

A delete removes the access that the group gives. SonarQube Server also removes the permission and permission template grants of the group. The SonarQube Cloud documentation does not say if it does the same. Do not expect a new group with the same name to get the grants back.

The group list of SonarQube Cloud is eventually consistent. When a refresh finds a name or a description that differs from the state, it reads the group again for about six seconds. A change outside Terraform thus shows some seconds later than other changes.

Import a group with `<organization>/<name>`.

## Example Usage

```terraform
resource "sonarqube_group" "example" {
  organization = "my-organization"
  name         = "Developers"
  description  = "Developers with project access"
}
```
