# sonarqube_cloud_organization_default_quality_gate (Resource)

Sets the default quality gate of a SonarQube Cloud organization. Each project that has no quality gate of its own uses the default.

The gate can be one that Terraform does not manage, such as the built-in Sonar way gate, which the `sonarqube_cloud_quality_gate` data source finds.

The organization must be on the Team or the Enterprise plan. On the Free plan, SonarQube Cloud refuses to change the default.

~> **The API cannot remove a default.** `terraform destroy` drops this resource from the state and gives a warning, but the organization keeps its default. SonarQube Cloud refuses to delete the default quality gate, so before you destroy a quality gate that is the default, set a different quality gate as the default.

## Example Usage

```terraform
# The destroy of this resource does not change the default. Before you destroy
# a gate that is the default, set a different gate as the default.
resource "sonarqube_cloud_organization_default_quality_gate" "example" {
  organization    = "my-organization"
  quality_gate_id = sonarqube_cloud_quality_gate.example.id
}
```
