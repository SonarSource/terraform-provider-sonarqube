# sonarqube_cloud_project_automatic_analysis (Resource)

Turns Automatic Analysis on or off for a SonarQube Cloud project. When Automatic Analysis is off, the project gets its analyses from a CI pipeline.

To turn Automatic Analysis on, the project must be bound to a repository, and it must be the only project bound to that repository. SonarQube Cloud then checks the repository in the background.

~> **Destroy keeps the setting.** Terraform removes this resource from the state, but the project keeps its current setting.

## Example Usage

```terraform
# The project gets its analyses from a CI pipeline. The destroy of this
# resource does not change the setting of the project.
resource "sonarqube_cloud_project_automatic_analysis" "example" {
  organization = "my-organization"
  project_key  = "my-project"
  enabled      = false
}
```
