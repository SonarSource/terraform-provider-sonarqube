# sonarqube_cloud_organization_default_permission_template (Resource)

Sets the default permission template of a SonarQube Cloud organization. A new project whose key matches no project key pattern of a template gets the permissions of the default.

The template can be one that Terraform does not manage, such as the template that SonarQube Cloud made with the organization.

~> **The API cannot remove a default.** `terraform destroy` drops this resource from the state and gives a warning, but the organization keeps its default. SonarQube Cloud refuses to delete the default permission template, so before you destroy a permission template that is the default, set a different permission template as the default.

## Example Usage

```terraform
# The destroy of this resource does not change the default. Before you destroy
# a template that is the default, set a different template as the default.
resource "sonarqube_cloud_organization_default_permission_template" "example" {
  organization = "my-organization"
  template_id  = sonarqube_permission_template.example.id
}
```
