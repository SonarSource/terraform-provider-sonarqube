# sonarqube_cloud_organization_default_quality_profile (Resource)

Sets the default quality profile of a language in a SonarQube Cloud organization. Each project that has no quality profile of its own for the language uses the default.

The profile can be one that Terraform does not manage, such as a built-in profile, which the `sonarqube_quality_profile` data source finds.

A custom profile needs the Team or the Enterprise plan, and a MISRA built-in profile needs the MISRA entitlement.

~> **The API cannot remove a default.** `terraform destroy` drops this resource from the state and gives a warning, but the organization keeps its default. SonarQube Cloud refuses to delete the default quality profile, so before you destroy a quality profile that is the default, set a different quality profile as the default.

## Example Usage

```terraform
# The destroy of this resource does not change the default. Before you destroy
# a profile that is the default, set a different profile as the default.
resource "sonarqube_cloud_organization_default_quality_profile" "java" {
  organization        = "my-organization"
  language            = "java"
  quality_profile_key = sonarqube_quality_profile.backend.key
}
```
