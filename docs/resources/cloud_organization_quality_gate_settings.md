# sonarqube_cloud_organization_quality_gate_settings (Resource)

Manages whether a SonarQube Cloud organization ignores coverage and duplication conditions on changes with fewer than 20 new lines. A project administrator can turn this setting off for a project when the organization setting is on.

~> **A change resets the projects.** When the value changes, SonarQube Cloud writes the new value to all projects of the organization, and project overrides are lost. Terraform sends no change when the value is already correct.

~> **Destroy keeps the setting.** Terraform removes this resource from state, but the organization keeps its current setting.

## Example Usage

```terraform
resource "sonarqube_cloud_organization_quality_gate_settings" "example" {
  organization         = "my-org"
  ignore_small_changes = true
}
```
