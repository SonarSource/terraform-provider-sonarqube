# sonarqube_project_quality_profile (Resource)

This resource sets the quality profile that a project uses for the language of the profile. A project uses the default profile of the organization for each language that has no such assignment. Use one resource for each language of the project. Do not use two resources for the same project and language: each apply then changes the assignment of the other.

A change of `quality_profile_key` to a different profile of the same language changes the assignment in place. A change to a profile of a different language replaces the resource: the project then uses the default profile again for the earlier language. When the plan does not know the key yet, for example for a profile that the same apply creates, the plan shows an update. The apply then also removes the assignment of the earlier language.

When someone changes the profile of the project outside of Terraform, the next plan shows the change. When the profile is deleted, the project uses the default profile again. If the configuration still names the key of the deleted profile, the next plan fails, because the profile does not exist.

A destroy makes the project use the default profile of the organization for the language again.

## Permissions

The token needs one of these permissions: Administer Quality Profiles on the organization, the permission to edit the profile, or Administer on the project. SonarQube Cloud permits this resource only on the Team and the Enterprise plans. When the organization moves to a plan without custom profiles, SonarQube Cloud refuses to remove the assignment. A destroy then only removes the resource from the state, with a warning.

## Import

Import an assignment with `<organization>/<project_key>/<language>`. When the project uses the default profile for the language, the import gets the key of the default profile.

## Example Usage

```terraform
resource "sonarqube_quality_profile" "backend" {
  organization = "my-organization"
  language     = "java"
  name         = "Backend"
}

# The project uses the Backend profile for java. For the other languages, it
# uses the default profiles of the organization.
resource "sonarqube_project_quality_profile" "backend" {
  organization        = "my-organization"
  project_key         = "my-project"
  quality_profile_key = sonarqube_quality_profile.backend.key
}
```

## Schema

### Required

- `organization` (String) Key of the organization that owns the project and the profile.
- `project_key` (String) Key of the project.
- `quality_profile_key` (String) Key of the quality profile, for example the `key` of a `sonarqube_quality_profile` resource or data source. A built-in profile is permitted.

### Read-Only

- `id` (String) `<organization>/<project_key>/<language>`.
- `language` (String) Key of the language of the profile, such as `java`.

## Import

Import is supported using the following syntax:

The [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import) can be used, for example:

```shell
# The ID is <organization>/<project_key>/<language>.
terraform import sonarqube_project_quality_profile.backend "my-organization/my-project/java"
```
