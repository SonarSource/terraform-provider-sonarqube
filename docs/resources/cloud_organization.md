# sonarqube_cloud_organization (Resource)

Manages a SonarQube Cloud organization. Organizations exist in SonarQube Cloud only.

Take care against a production instance: a deletion starts billing events, and it can leave a binding to a DevOps platform behind.

## Change the key

SonarQube Cloud renames the organization in place and keeps its content. But in Terraform, each resource with an `organization` attribute that refers to the key gets a new value. The plan refuses it for a `sonarqube_project`, because a new project would lose the analysis history, issues and settings. Most other resources are replaced: Terraform deletes the object and makes a new one. A replaced group loses the members and permissions that Terraform does not manage.

To keep these objects, do these steps:

1. Remove each resource that refers to the key from the state, for example `terraform state rm sonarqube_project.example`. Find them with `terraform state list`.
2. Apply the new key to the organization only, with `terraform apply -target=sonarqube_cloud_organization.example`.
3. Import the removed resources with the new key, for example with an `import` block with the ID `<new key>/<project key>` for a project. Then run `terraform apply`. The plan shows only imports.

These steps cannot keep a `sonarqube_cloud_scoped_organization_token`, because an import does not restore its secret. Revoke the token before step 1, with `terraform destroy -target=sonarqube_cloud_scoped_organization_token.example`. Do it before the rename, because after it Terraform cannot find the old token, and the old secret stays valid. The last `terraform apply` makes a new token. Give its secret to the places that use the old one.

## Schema

### Required

- `key` (String) Key of the organization. Must be unique. A new key renames the organization in place. The plan refuses it for each `sonarqube_project` that refers to the key, and most other resources that refer to it are replaced. The section "Change the key" of this resource tells how to keep them.
- `name` (String) Name of the organization.

### Optional

- `avatar_url` (String) Address of the avatar of the organization.
- `description` (String) Description of the organization.
- `url` (String) Address of the web page of the organization.

### Read-Only

- `id` (String) Identifier of the organization. Holds the same value as `key`.
