# sonarqube_permission_template (Resource)

This resource manages a permission template and all its grants. When a user creates a project, the template whose project key pattern matches the key gives its permissions to the new project. When no pattern matches, the default template of the organization does. A change to a template does not change the projects that exist.

## All the grants

The resource controls all the grants of the template: the grants of the groups, the users and the project creator. A grant that is not in the configuration, also one that a user added in the UI, shows as a change in the next plan, and the apply removes it.

The resource refuses the `Anyone` group. If the template gives a permission to `Anyone`, for example after a change in the UI, the next apply removes it.

## Plans

SonarQube Cloud needs the Team or the Enterprise plan to create a template or to change its grants. On the Free plan, the apply fails. The token must have the Administer permission on the organization.

## Users

A user must be a member of the organization. If the user is not a member, the apply fails.

## The default template

SonarQube Cloud refuses to delete the default template. Before you destroy a template that is the default, set a different template as the default.

## Project permissions

The project permissions are `admin`, `codeviewer`, `issueadmin`, `securityhotspotadmin`, `scan` and `user`. SonarQube Cloud also has `architectureadmin`.

## Example Usage

```terraform
resource "sonarqube_group" "developers" {
  organization = "my-organization"
  name         = "Developers"
}

resource "sonarqube_permission_template" "backend" {
  organization        = "my-organization"
  name                = "Backend projects"
  description         = "Grants of the backend projects."
  project_key_pattern = "my-organization_backend-.*"

  project_creator_permissions = ["admin"]

  group {
    name        = sonarqube_group.developers.name
    permissions = ["user", "codeviewer", "issueadmin"]
  }

  user {
    login       = "alice@github"
    permissions = ["admin"]
  }
}
```

## Schema

### Required

- `name` (String) Name of the template. The names in an organization must be different, also when the case is ignored.
- `organization` (String) Key of the organization that owns the template. A change replaces the template.

### Optional

- `description` (String) Description of the template.
- `group` (Block Set) Project permissions of a group. Each group can appear once. (see [below for nested schema](#nestedblock--group))
- `project_creator_permissions` (Set of String) Project permissions that the template gives to the user who creates the project.
- `project_key_pattern` (String) Java regular expression. The template applies to the new projects whose key matches it. Two templates of an organization cannot have the same pattern.
- `user` (Block Set) Project permissions of a user. Each user can appear once. (see [below for nested schema](#nestedblock--user))

### Read-Only

- `id` (String) Identifier of the template.
