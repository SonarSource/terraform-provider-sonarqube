# sonarqube_cloud_organization_permissions (Resource)

This resource manages the complete set of organization permissions for one group or user. Create removes existing grants that are not in `permissions`. Destroy removes the selected principal's organization grants. It does not change other principals.

The allowed permissions are `admin`, `gateadmin`, `profileadmin`, `architectureadmin`, `provisioning`, and `scan`. The `Anyone` group is not supported. A FREE organization accepts group permission changes.

The resource finds the group by its exact name. If somebody renames the group outside Terraform, the next plan creates the resource again, and the apply fails because no group has the configured name. A rename in a `sonarqube_group` resource replaces this resource and keeps the permissions.

SonarQube Cloud refuses to remove the last organization administrator. If a plan removes the last `admin` grant, the apply fails and reports the server error. Keep another administrator before you remove that grant.

## Delays

When a refresh finds no permissions for a group, it reads the list again for about seven seconds, because the list can lag after a group change. A removal outside Terraform thus shows some seconds later than other changes.

For some seconds after a group is created, renamed, or deleted, SonarQube Cloud can refuse permission changes for a group with that name. Create and update then try each call again for about ten seconds. Thus a group name that does not exist, for example after a typing error or a deletion outside Terraform, shows its error about ten seconds later.

## Example Usage

```terraform
resource "sonarqube_cloud_organization_permissions" "developers" {
  organization = "my-org"
  group_name   = "Developers"
  permissions  = ["scan", "gateadmin"]
}
```

## Import

```terraform
import {
```

The [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import) can be used, for example:

```shell
# The ID of a group is <organization>/group/<name>.
terraform import sonarqube_cloud_organization_permissions.developers my-org/group/Developers

# The ID of a user is <organization>/user/<login>.
terraform import sonarqube_cloud_organization_permissions.alice my-org/user/alice@github
```
