# sonarqube_quality_profile_editor (Resource)

This resource lets one group or one user edit one custom quality profile. The editor can then change the rules, the projects, the name and the parent of the profile, and let other groups and users edit it too. The editor does not need the Administer Quality Profiles permission. Destroy takes the right from the editor. A change to any attribute replaces the resource.

A rename of the profile does not change the resource. When someone takes the right from the editor outside of Terraform, or deletes the profile, the next plan shows that the resource must be created again.

## Requirements

Built-in profiles cannot have editors. A user must be a member of the organization. The token needs the Administer Quality Profiles permission, or the right to edit the profile.

SonarQube Cloud permits editors only on the Team and the Enterprise plans. On a different plan, a refresh does not find the editor, and the next apply fails.

This resource uses web services that SonarQube Cloud marks as internal.

## Import

Import a group with `<organization>/<quality_profile_key>/group/<group_name>`, and a user with `<organization>/<quality_profile_key>/user/<login>`. The group name can contain `/`.

## Example Usage

```terraform
resource "sonarqube_quality_profile" "backend" {
  organization = "my-organization"
  language     = "java"
  name         = "Backend"
}

# The members of the group can edit the Backend profile.
resource "sonarqube_quality_profile_editor" "backend_team" {
  organization        = "my-organization"
  quality_profile_key = sonarqube_quality_profile.backend.key
  group_name          = "backend-team"
}

# The user can edit the Backend profile too.
resource "sonarqube_quality_profile_editor" "lead" {
  organization        = "my-organization"
  quality_profile_key = sonarqube_quality_profile.backend.key
  login               = "my-login@github"
}
```

## Schema

### Required

- `organization` (String) Key of the organization that owns the profile.
- `quality_profile_key` (String) Key of a custom quality profile, for example the `key` of a `sonarqube_quality_profile`.

### Optional

- `group_name` (String) Name of the group. Use the same case as the group, so that the configuration and SonarQube Cloud show the same name. Set exactly one of `group_name` and `login`.
- `login` (String) Login of the user, with the same case. Set exactly one of `group_name` and `login`.

### Read-Only

- `id` (String) The import ID.

## Import

Import is supported using the following syntax:

The [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import) can be used, for example:

```shell
# The ID is <organization>/<quality_profile_key>/group/<group_name> for a group.
terraform import sonarqube_quality_profile_editor.backend_team "my-organization/my-profile-key/group/backend-team"

# The ID is <organization>/<quality_profile_key>/user/<login> for a user.
terraform import sonarqube_quality_profile_editor.lead "my-organization/my-profile-key/user/my-login@github"
```
